# WeakAuras for WoW Forever

Auras here are ported to ForeverAuras in the `_forever_` client. README.md has the setup, commands and porting steps.

- A port is done when its tests pass, its break script shows the tests catch broken code, and the encoder round-trips
  the string. Then the user checks it in game.
- Never write to ForeverAuras.lua while WoW is running.
- When a port teaches something new, add it to LESSONS.md.
- Anything the user reads follows `../reference/writing.md` (a private sibling repo).
